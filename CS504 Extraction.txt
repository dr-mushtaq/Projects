1.2 Difference between Computer Science and Software Engineering
 Difference between Software and Other Systems
Distinguishes a software system from other systems:
          Other Systems	                                                Software
Cars, TVs, bulbs etc. are physical systems.	             Software is a non-physical system.
They can wear out with time due to wear and tear.	     Software does not wear out with time.
Their physical parts can become damaged or fused.	     Software problems are called bugs/defects.
A damaged part can usually be replaced to fix the system.    A bug cannot simply be fixed by getting a new copy/CD if the same bug exists in it.
They have a limited physical life.	                     Software does not have a physical life based on wear and tear.
Example: fused bulb → replace bulb → works again.	     Example: buggy software → new copy with same bug → still buggy.
